# Data Attribution

This project uses public data from the U.S. Census Bureau American Community Survey (ACS).

The project code, transformations, validation logic, SQL analysis, documentation, and portfolio presentation were created for this repository.

Data source:

- U.S. Census Bureau
- American Community Survey 5-Year API
- Puerto Rico state FIPS: `72`

No Census API key is required for the small request volume used by this starter pipeline, although the Census API may support keys for larger workloads.
